Build your own line

Set up a VPN server on a cloud server you control, then add it to Vola by scanning one QR code. Once the server is running, the setup script takes about two minutes.

What you need

  • A cloud server you control, running Ubuntu 22.04 or 24.04 (x86_64 or arm64) with a public IPv4 address. The smallest size is enough: 1 vCPU and 1 GB of memory.
  • A way to run commands on it: an SSH app, a computer, or your provider's browser console.
  • A name that points to the server. No domain? The script uses a free name like 203-0-113-7.sslip.io, which always points to your server's address.
  • Vola doesn't provide, rent or manage servers. The server, what it costs and what passes through it are yours.

1 · Get a server

Any cloud provider works. Some have a free tier — Oracle Cloud's Always Free offer is one option. Free allowances and their terms change, so check the provider's current terms before you rely on one.

2 · Open three ports

In your provider's firewall — it may be called a security list, security group or network security group — allow inbound traffic on:

  • UDP 500
  • UDP 4500
  • TCP 80 — used for a few seconds to get and renew the certificate

The script sets up the server's own firewall for you.

Where is this at my provider?
  • Oracle Cloud: add ingress rules for UDP 500, UDP 4500 and TCP 80 to the subnet's security list or the instance's network security group. The kit handles the iptables REJECT rules that Oracle's Ubuntu image has.
  • AWS (EC2 / Lightsail): add inbound rules for UDP 500, UDP 4500 and TCP 80 to the instance's security group (on Lightsail, the instance's Networking tab).
  • Azure: add inbound security rules for UDP 500, UDP 4500 and TCP 80 to the VM's network security group.
  • Google Cloud: create a VPC firewall rule that allows ingress on UDP 500, UDP 4500 and TCP 80 to the instance, for example through a network tag.

3 · Run one command

Connect to your server and run:

curl -fsSLO https://bluebirdconnect2026.github.io/volavpn-site/kit/vola-server.sh && sudo bash vola-server.sh install --user phone

phone is the VPN username. To use another one, start with a letter; then letters, digits, - or _. Up to 32 characters.

Read the script before you run it 
curl -fsSLO https://bluebirdconnect2026.github.io/volavpn-site/kit/vola-server.sh
curl -fsSLO https://bluebirdconnect2026.github.io/volavpn-site/kit/SHA256SUMS
sha256sum -c SHA256SUMS
less vola-server.sh
sudo bash vola-server.sh install --user phone

The script is plain text. SHA256SUMS lets you check that the file is the one published at https://bluebirdconnect2026.github.io/volavpn-site/kit.

Have a domain? Point its A record at the server first, then add --host vpn.example.org.

The script installs strongSwan and gets a certificate from Let's Encrypt — or from ZeroSSL if Let's Encrypt is busy — that iPhone trusts without installing anything. If you use the free sslip.io name, also add --email with your address so the ZeroSSL fallback can work.

4 · Scan the code

When the script finishes, it shows a QR code for the user it created. The code includes the password, so don't post it or keep a screenshot.

In Vola, tap Add a line, then Scan.

The password is shown only once. Lost it? Run sudo vola-server user add phone --reset for a new one. To show the code again without the password, run sudo vola-server qr phone.

5 · Run a proof

Vola checks the new line before you rely on it. Once it passes, the line is yours — it keeps working after the starter line closes.

Keeping it running

The script turns on automatic security updates and certificate renewal. Check the server any time with sudo vola-server status, or remove everything with sudo vola-server uninstall.

Sharing with someone? Give each person their own user (sudo vola-server user add <name>) so you can remove one without affecting the others.

You're responsible for your server and how it's used, including your cloud provider's terms.
